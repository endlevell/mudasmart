## Aturan pakai

- Clear space minimal = 25% lebar ikon di tiap sisi.
- Ukuran minimum aman: 24px (konsep 1 tetap terbaca; detail kilau mulai hilang di bawahnya).
- Jangan rotasi/skew, jangan ganti warna di luar palet.
- Latar gelap (`#073D2C`–`#0B6E4F`) → pakai mono-light atau appicon.

## Export PNG

```bash
inkscape file.svg --export-png=file.png --export-width=1024
```
